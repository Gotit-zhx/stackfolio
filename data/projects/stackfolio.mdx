## 一个可以持续发布的个人网站

Stackfolio 把个人介绍、项目案例和技术文章放在同一套内容模型中。项目详情页可以同时链接源码仓库和独立在线演示，博客内容使用 MDX 编写，发布前可以在管理台预览和保存草稿。

## 从本地到云服务器

- **网站**：Next.js、TypeScript、Tailwind CSS 和 Contentlayer，生成适合小型云主机的 standalone 镜像。
- **内容**：项目和文章均由版本化的 MDX 文件驱动，保留 Gitflow 审阅和可回退的发布路径。
- **运行**：Stackfolio、PostMaker、百草园分别使用独立 Docker Compose project，数据卷相互隔离。
- **入口**：Caddy 负责公网 HTTP/HTTPS 反向代理；没有域名时也可以先用服务器 IP 做受限验收。
- **管理**：个人管理台只监听服务器回环地址，通过 SSH 隧道访问，并用访问码和会话 Cookie 保护。

## 安全边界

资源监控仅对登录后的本人管理台提供，不在公开站点展示 CPU、内存、磁盘、容器列表或环境变量。公网演示关闭注册和未审核的写入入口，应用密钥、管理台访问码与数据备份不进入 Git。

本项目由我独立编写。案例描述依据当前公开仓库和可复现的部署配置，不使用未经验证的用户规模或性能数字。
