# 个人网站视觉风格调研

调研日期：2026-10-31

以下参考来自公开网站的现场访问。本次对话中已展示现场页面截图；文档中的图片链接使用各站点公开的分享图，便于后续复看。页面会随着原作者更新而变化，因此只把它们作为视觉方向参考，不复制任何站点的布局或代码。

## 选项 A：深色工程作品集

参考： [Brittany Chiang](https://brittanychiang.com/)

![Brittany Chiang 深色工程作品集](https://brittanychiang.com/og.png)

特点：

- 深海军蓝背景、低饱和辅助文字和明确的无衬线层级。
- 首页先给出身份定位，然后按 About、Experience、Projects、Writing 组织证据。
- 项目、经历和技术栈都能快速扫描，适合招聘者阅读。
- 暗色背景可以衬托项目截图，但需要控制对比度和长文阅读疲劳。

适合本站的改造：

- 保留“身份定位 + 精选项目 + 经历摘要”的首页结构。
- 项目卡片提供 GitHub 和在线演示两个入口。
- 博客单独使用更宽的阅读列，避免整站都像简历。

实现成本：中等。普通 CSS、Next.js 和 Markdown 即可实现，不需要复杂动画。

## 选项 B：浅色文字型个人博客

参考： [Lee Robinson](https://leerob.com/)

![Lee Robinson 浅色文字型个人主页](https://leerob.com/opengraph-image.png?opengraph-image.e50fc1a6.png)

特点：

- 大量留白、衬线正文和极少的装饰元素。
- 首页内容以个人简介、Notes 和 Blogs 为主，个人身份与长期写作放在同一层级。
- 通过短列表和日期组织内容，信息密度低但阅读路径清晰。
- 视觉维护成本很低，适合持续写作和快速部署。

适合本站的改造：

- 首页突出“AI 应用开发 / AI Agent / 工程化”定位和最新文章。
- 项目页使用简洁的案例说明，不用大面积装饰卡片。
- 中文长文可以直接使用 Markdown，适合后续持续更新。

实现成本：低。适合作为稳定的第一版基础风格。

## 选项 C：明快插画型技术博客

参考： [Josh W. Comeau](https://www.joshwcomeau.com/)

![Josh Comeau 明快插画型技术博客](https://www.joshwcomeau.com/opengraph-image.png?cac0cc658da9fd03)

特点：

- 蓝色天空、云朵形状、彩色强调色和明显的品牌性。
- 首页把文章和教程放在第一屏，分类、搜索、主题切换和 RSS 都很明显。
- 通过插画、微交互和轻量动画建立记忆点。
- 内容体验强，但插画和动效需要持续维护，设计工作量高于普通博客。

适合本站的改造：

- 用一套统一的 AI、Agent、数据流插画作为项目封面。
- 博客文章保留轻量互动，但项目详情页以截图、架构图和演示为主。
- 使用少量强调色区分项目状态、技术标签和文章分类。

实现成本：中高。需要额外准备插画、动效和响应式细节。

## 选项 D：沉浸式 3D 作品集

参考： [Bruno Simon](https://bruno-simon.com/)

![Bruno Simon 沉浸式 3D 作品集](https://bruno-simon.com/social/share-image.png?cb=a)

特点：

- Three.js/WebGL 全屏场景代替传统首页排版。
- 网站本身就是能力演示，访问者通过探索场景进入项目和履历。
- 记忆点极强，适合创意开发、3D 和互动体验方向。
- 对移动端、低性能设备、可访问性和信息检索都提出更高要求。

适合本站的改造：

- 不建议作为第一版的主导航。
- 可以把它降级为某个项目的在线演示，或者在首页加入轻量的 Canvas 背景实验。
- 主要项目和博客仍应保留传统链接，确保招聘者能快速阅读。

实现成本：很高。需要 Three.js 场景、资源优化、交互设计和移动端降级方案。

## 选项 E：实验性编辑设计

参考： [Rauno Freiberg](https://rauno.me/)

![Rauno Freiberg 实验性编辑设计](https://rauno.me/og4.png)

特点：

- 浅灰画布、黑色大字号、几何图形和横向分栏。
- 首页像一张动态海报，身份介绍和项目入口被组合成视觉构图。
- 通过滚动、拖拽和局部动效表达设计能力，而不是堆积文字。
- 视觉辨识度高，但普通用户可能需要短暂适应。

适合本站的改造：

- 使用大标题呈现个人定位，项目入口采用宽幅视觉卡片。
- 项目详情页用“问题 / 方案 / 技术 / 演示”四段式案例结构。
- 只借鉴排版和动效节奏，避免让博客正文也变成难读的实验界面。

实现成本：中高。需要细致的响应式排版和交互状态设计。

## 初步建议

对当前求职目标，最稳妥的起点是 **A + B 的组合**：

- 首页采用 A 的证据结构，让招聘者先看到定位、项目和技术能力。
- 博客和项目详情页采用 B 的阅读方式，保证中文长文和案例说明易读。
- 从 C 借鉴少量插画或强调色，增加个人辨识度。
- D 和 E 可作为后续增强方向，不作为第一版的核心导航。
